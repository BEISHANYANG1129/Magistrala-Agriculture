## 已实施规则

- 地图数据放入选中对象分组的 `attributes.metadata.field_map`，包括版本、底图、分区，以及以设备 ID 为键的设备点位。已有 location/perimeter、标签和其他元数据保留。
- 同一设备可在不同分组地图中拥有不同点位，不再读取全局 `position` 作为地图点位。
- 默认展示直接关联到当前分组的设备；使用与分组设备页一致的对象分组关系，不使用人员组成员关系。
- 不自动建立设备关联、通道连接、子分组或权限。
- 设备定位只更新当前分组地图；保存前重新检查设备仍关联该组。
- 保存读取最新分组信息，保留无关元数据；检测同一地图字段的并发修改，不静默覆盖。
- 分组切换及刷新需处理未保存的底图/分区草稿；读取结果需隔离，避免跨分组异步响应串写。
