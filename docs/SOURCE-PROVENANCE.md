本仓库包含这些基线之上的当前工作区修改，包括农业界面、区域服务、核心 Compose 参数、登录会话补丁和 Bootstrap 兼容补丁。核心源码以普通文件随仓库提交，未使用失效的旧 gitlink 或 Git 子模块，也未导入无关上游提交历史。

发布整理增加了初始化、跨平台启动和完整 Docker 部署流程，固定已运行核心镜像摘要，移除了部署者的私有凭据、运行历史、设备映射、上传图片和本机工具缓存。需要配置的数据以模板提供。初始化时每个部署独立生成密码、服务令牌、TLS 证书和会话密钥。

原项目的功能说明和测试源文件保留；上游版权和许可保留在相应源文件及 `magistrala/LICENSE`。核心容器镜像和上游 UI 来自公开 GHCR；本仓库不包含这些外部镜像的完整源代码。
